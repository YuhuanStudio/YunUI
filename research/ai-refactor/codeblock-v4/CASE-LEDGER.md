## Source changes in scope

- `src/content/remark-code-meta.ts` parses only `showLineNumbers`, bounded `{line-ranges}`, and `filename=...`; all other info tokens are ignored.
- `src/content/markdown-renderer.tsx` registers that remark pass and consumes only the sanitized language/metadata classes to configure the public `CodeBlock` and `onCodeEdit` payload.
- `src/content/sanitize-markdown.ts` adds only a bounded encoded filename class token to the existing code-class allowlist; no event, style, or arbitrary `data-*` attr was added.
- `src/patterns/code-block.tsx` always uses its existing lightweight tokenizer; line-number visibility now controls only the gutter. Its final fallback emits unmatched characters rather than dropping them; empty-code tabs remain empty.
- Integration/regression coverage is in `src/__tests__/markdown-code-meta.test.tsx` and `src/__tests__/code-block-data-contract.test.tsx`.

No Shiki import was added to `patterns`, no exported `CodeBlock` name changed, and no style/default appearance was changed in the public production component files.
