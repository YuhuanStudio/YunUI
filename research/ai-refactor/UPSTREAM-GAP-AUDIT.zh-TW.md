# Beautiful UI ChatExperience 上游差異稽核

**結論：不能以「可塞進 `ChatMessage.children`」作為已有可重用 UI 的證據。** YunUI 有可組合的 message/body/citation primitives，但至少四個上游 chat-facing visual units 沒有直接可 import 的 YunUI 對應元件：`StreamingText`（回答附來源清單、message actions、追問）、`ContextCards`（會話檢索片段卡組）、`SelectionActions`（選取段落的 contextual edit bar）、`DiffTable`（提議 edits 的逐項選取與 apply footer）。另 `DiffTable` 與 `SelectionActions` 同時缺少符合 host-owned execution 的公開行為契約。四個 React component 的 source-derived adaptation 已放在隔離的 Vite review app：[`upstream-gap-review/`](./upstream-gap-review/README.md)，目前每項仍待 owner 分別審核；沒有改 production exports/source。

## Review packet 的狀態與邊界

以下是 review fixture 覆蓋的行為；互動由頁面明確操作模擬 host state/callback，不會自動轉態或呼叫任何模型／文件服務。

| 元件提案 / 上游來源 | 可檢視操作狀態 | host-owned data / failure boundary | 候選 consumer 可直接 reuse 的缺口 |
| --- | --- | --- | --- |
| Streaming answer (`StreamingText.tsx:91-226`) | complete/streaming/error/cancelled/empty；host advance chunks；展開來源；送出 follow-up 與 action request | host answer/source list/followups/state；callback 僅發 request，不生成/重試答案 | 回答 body 之後的 source summary/list + follow-up/action row 缺一個直接 import 的視覺單元 |
| Context group (`ContextCards.tsx:48-112`) | 多筆 retrieved chunks、empty；source open/include callback | host chunk ID/title/excerpt/source/href；檢索與權限檢查不屬 UI | 多 chunk card group 缺直接元件；`InlineCitation`/`ChatAttachment` 僅原子或單附件 |
| Selection action (`SelectionActions.tsx:129-149,303-`) | host selection；Explain/Improve/Shorten/Grammar/custom instruction；idle/busy/result/error/cancelled；Accept/Dismiss；窄寬可展開 actions | host 提供選區、結果、busy/error/cancelled；失敗保留原文；不內建 rewrite | contextual selection toolbar + result/acceptance UI 缺直接元件；列尾 `ChatMessage.actions` 無法取代錨點在所選文字旁的工具列 |
| Proposed change review (`DiffTable.tsx:63-80,106-124,157-245`) | 各 change include/exclude；無選取時 Apply disabled；idle/busy/applied/error/cancelled/disabled；Apply/Reject request | 穩定 change IDs/selected state、實際 apply/persistence/rollback 全由 host 負責；沒有成功回應不得顯示 applied | 可直接 import 的 proposal review table/summary/apply-request/footer 缺失；diff rendering API 不承擔決策/套用工作流 |
