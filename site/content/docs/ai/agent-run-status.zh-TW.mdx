import { AgentRunStatus } from "yunui/ai";

一個版面穩定的狀態面，用於呈現 agent 目前或終態，並透過 `role="status"` / `aria-live` 播報。階段和本地化標籤由 host 提供；元件只負責狀態呈現，不會推進執行流程。

它刻意與 [Agent Timeline](/docs/ai/agent-timeline) 分開：狀態在整個回合中固定停留在同一處，而時間軸的每一列則累積成持久的處理歷史。你提供已本地化的即時 `label`;YunUI 負責動態與幾何。

## 匯入

```tsx
import { AgentRunStatus } from "@yuhuanowo/yunui/ai";
```

## 基礎用法

<ComponentPreview title="基礎用法">
  <AgentRunStatus label="Thinking…" phase="thinking" />
</ComponentPreview>

## 階段

舊的 `AgentRunPhase` 仍包含 `thinking`、`acting`、`observing`、`reflecting`、`responding` 和 `waiting`。`phase` 也可透過新增的 `AgentRunState` 接受終態 `completed`、`failed` 和 `cancelled`；這些終態與 `waiting` 預設 `active={false}`。階段變化及其本地化標籤由 host 管理。

<ComponentPreview title="階段">
  <div className="flex flex-col gap-2">
    <AgentRunStatus label="Reading files…" phase="acting" />
    <AgentRunStatus label="Reviewing the results…" phase="observing" />
    <AgentRunStatus label="Writing response…" phase="responding" />
    <AgentRunStatus label="Waiting for approval" phase="waiting" />
    <AgentRunStatus label="回合已完成" phase="completed" />
    <AgentRunStatus label="工具執行失敗" phase="failed" />
  </div>
</ComponentPreview>

## 暫停

在任何階段傳入 `active={false}` 即可讓該列靜止（例如回合被暫停），且不會收合它。

<ComponentPreview title="暫停">
  <AgentRunStatus label="Paused" phase="acting" active={false} />
</ComponentPreview>
