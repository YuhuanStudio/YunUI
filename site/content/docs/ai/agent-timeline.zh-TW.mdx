import { AgentTimeline } from "yunui/ai";

助理回合內的緊湊活動元件，包含推理展開區、帶輸出與檔案差異的工具列、任務結果和工具批准。可與 Markdown 回覆一起放在 `ChatMessage` 內。宿主提供 `AgentTimelineEntry[]`、狀態與回呼。舊 `AgentTimelineBlock` 保留 reasoning/tool/approval 聯集；新增 Entry API 支援任務、取消的工具與富內容 `outputContent`。

## 匯入

```tsx
import { AgentTimeline } from "@yuhuanowo/yunui/ai";
```

## 基礎用法

每個區塊都是以 `kind` 區分的聯合型別。`reasoning` 區塊會將推理過程收合在一行標籤之後;`tool` 區塊顯示動詞、可選的等寬 `summary`、狀態符號，並在設定 `command`／`output` 時提供可展開的主控台。

<ComponentPreview title="基礎用法">
  <div className="w-full max-w-xl">
    <AgentTimeline
      blocks={[
        { kind: "reasoning", id: "r1", label: "Thought for 3s", content: "The user wants the failing test isolated. I'll grep for the assertion, run only that file, then read the traceback." },
        { kind: "tool", id: "t1", verb: "Search", summary: "expect(sum).toBe", status: "done", icon: "search" },
        { kind: "tool", id: "t2", verb: "Run", summary: "pnpm test sum.test.ts", status: "done", icon: "terminal", command: "pnpm test sum.test.ts", output: "✓ adds positives\n✗ adds negatives\n\n1 failed, 1 passed" },
      ]}
    />
  </div>
</ComponentPreview>

## 工具狀態與巢狀

`status` 決定節點外觀：`running` 以品牌色旋轉載入符號、`done` 顯示勾選、`error` 會將該列與主控台改為紅色。設定 `indent` 可將一列往內縮排一層——例如將子代理步驟置於派發它的呼叫之下。

      ]}
    />

## 授權提示

`approval` 區塊會算繪內嵌的允許／拒絕面板，並以區塊 `id` 觸發 `onApprove` / `onReject`。決定之後，傳入 `decision`（與 `decidedLabel`）即可將其凍結為已解析狀態。

<ComponentPreview title="授權提示">
  <div className="w-full max-w-xl">
    <AgentTimeline
      blocks={[
        { kind: "reasoning", id: "r1", label: "Planned the migration", content: "I need to delete the legacy table before recreating it." },
        { kind: "approval", id: "a1", title: "Run command", verb: "bash", message: "This will drop the staging database. Continue?", argsText: "$ dropdb yunui_staging", allowLabel: "Allow", denyLabel: "Deny" },
        { kind: "approval", id: "a2", title: "Write file", verb: "fs.write", message: "Overwrite migrations/003.sql", decision: "approved", decidedLabel: "Approved", allowLabel: "Allow", denyLabel: "Deny" },
      ]}
    />
  </div>
</ComponentPreview>

## 將推理算繪為 Markdown

推理內容預設以保留換行的純文字算繪。傳入 `renderContent` 即可接入 Markdown 算繪器（例如來自 `@yuhuanowo/yunui/content` 的 `MarkdownRenderer`），讓清單、程式碼與強調正確排版。

```tsx
import { MarkdownRenderer } from "@yuhuanowo/yunui/content";

<AgentTimeline
  blocks={blocks}
  renderContent={(text) => <MarkdownRenderer content={text} />}
/>
```

## 任務列、取消與詳情展開

新增的 `AgentTimelineEntry` 支援 `kind: "task"`，狀態為 `pending`、`running`、`done`、`failed` 或 `cancelled`。舊的 `AgentTimelineBlock[]` 仍可直接使用；舊型別維持封閉。已取消的工具請使用 `AgentTimelineCancelledToolBlock` 或 `AgentTimelineEntry[]`。

```tsx
import { AgentTimeline, type AgentTimelineEntry } from "@yuhuanowo/yunui/ai";

const blocks: AgentTimelineEntry[] = [
  { kind: "task", id: "review", label: "Review docs", amount: "12 pages", status: "running", step: 3, details: [{ id: "index", label: "Read the index", meta: "3 / 12" }] },
  { kind: "tool", id: "diff", verb: "Edit", summary: "docs/chat.mdx", status: "done", icon: "terminal", files: [{ id: "chat-doc", file: "docs/chat.mdx", additions: 2, deletions: 1, lines: [{ id: "line-add", text: "Add the menu API", tone: "add" }, { id: "line-del", text: "Remove stale guidance", tone: "del" }] }] },
  { kind: "tool", id: "cancelled", verb: "Run", summary: "pnpm test", status: "cancelled", icon: "terminal" },
];
```

摘要預設展開；reasoning、任務、工具輸出和檔案 diff 列預設收合。可用 `defaultOpen` 設定初始狀態，或搭配 `onToggleRow` / `onToggleDiff` 由 host 控制 `open`。`labels.summary(counts)` 會收到實際的步驟/reasoning/tool/task/approval 計數，不會推算訊息數。

透過 `AgentTimelineLabels` 可替換摘要、process/狀態、輸出和 diff 文案。`waitingForHost` 特別用於本地化等待 host 回應的 busy 狀態，但不會解決授權請求。

工具 `details` 可承載 context/add/delete 列，`files` 可包含統一 diff 列。長輸出保留在各自的捲動區域中。授權列的 `busy` 表示 host 正在準備回應，不會自動解決請求；可透過 `labels.waitingForHost` 本地化此狀態。`onApprove` / `onReject` 仍代表 host 實際作出的工具決策；沒有相應回呼時，決策按鈕會停用。使用者問答請改用[核准問答](/docs/ai/approval-question)。

新增的 `AgentTimelineToolEntryBlock.outputContent` 插槽可傳入宿主組合的節點，
例如從 `@yuhuanowo/yunui/content` 匯入的 `CodeBlock` 或 `MarkdownRenderer`。
它優先於純文字 `output`，顯示在工具的展開內容中。舊版
`AgentTimelineBlock.output` 仍是字串，工具資料和執行始終由宿主負責。
