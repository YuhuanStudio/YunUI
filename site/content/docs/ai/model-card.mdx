import { ModelCard, ProviderIcon } from "yunui/ai";

A card that summarizes an AI model: a provider/model icon, the display name, capability chips, copyable id badges, a short description, and a footer with the developer, context window, tier, and price. Pass `onClick` to make the whole card a keyboard-activatable button.

## Import

```tsx
import { ModelCard } from "@yuhuanowo/yunui/ai";
```

## Basic

The `icon` slot is host-rendered — pass a `<ProviderIcon>` (or `<ModelIcon>`) so the card stays framework-agnostic.

## Clickable card with copyable IDs

When `onClick` is provided, the card body selects the model while each ID badge remains its own copy action. This host fixture makes both actions available in the live preview.

<ComponentPreview
  title="Clickable card and independent copy actions"
  code={`import { useState } from "react";
import { ModelCard } from "@yuhuanowo/yunui/ai";

function Example() {
  const [selected, setSelected] = useState(false);
  return (
    <>
      <ModelCard
        name="GPT-4o"
        ids={["gpt-4o", "gpt-4o-latest"]}
        description="Click the card to select; click an ID to copy."
        onClick={() => setSelected((value) => !value)}
      />
      <output>{selected ? "Selected for routing" : "No model selected"}</output>
    </>
  );
}`}
>
  <ModelCardInteractiveDemo />
</ComponentPreview>
