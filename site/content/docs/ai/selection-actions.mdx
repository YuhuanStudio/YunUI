The host supplies the selected passage, edit state and result. The toolbar anchors to that passage; actions and custom instructions only request work. Keep/Discard callbacks leave persistence to the host. Busy, error and cancelled states never rewrite the original.

## Import

```tsx
import { SelectionActions } from "@yuhuanowo/yunui/ai";
```
