host 提供所選段落、狀態和改寫結果。工具列會錨定到這段文字；動作與自訂指令只發出請求。Keep／Discard 回呼交由 host 決定是否更新原文，busy／error／cancelled 都不會自動改寫。

## 匯入

```tsx
import { SelectionActions } from "@yuhuanowo/yunui/ai";
```
