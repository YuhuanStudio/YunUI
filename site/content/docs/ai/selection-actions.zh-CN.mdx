host 提供所选段落、状态和改写结果。工具栏锚定到这段文字；动作与自定义指令只发出请求。Keep／Discard 回调交由 host 决定是否更新原文，busy／error／cancelled 都不会自动改写。

## 导入

```tsx
import { SelectionActions } from "@yuhuanowo/yunui/ai";
```
