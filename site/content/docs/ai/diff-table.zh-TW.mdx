用穩定 row ID 和 selectedIds 控制要納入的新增／刪除。Apply／Reject 僅傳回選取 ID；host 回傳 applied 前不顯示成功。busy／disabled 鎖定操作；error／cancelled 保留資料，由 host 決定重試。
