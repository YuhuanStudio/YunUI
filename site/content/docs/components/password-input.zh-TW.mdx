import { PasswordInput } from "yunui";

內建顯示／隱藏切換的密碼輸入框。

## 匯入

```tsx
import { PasswordInput } from "@yuhuanowo/yunui";
```

## 用法

它轉發全部 `<input>` 屬性，因此可以直接替換表單裡原本的 `<Input type="password">`——受控或非受控皆可，`name`、`autoComplete`、`required` 等一應俱全。

<ComponentPreview title="Password input">
  <div className="w-full max-w-sm flex flex-col gap-4">
    <PasswordInput placeholder="Enter your password" defaultValue="correct-horse" />
    <PasswordInput placeholder="Confirm password" defaultValue="wrong" error="Passwords do not match." />
    <PasswordInput placeholder="Disabled" disabled />
  </div>
</ComponentPreview>

## 說明

- 切換按鈕是輸入框的 flex 同層元素，**不是**絕對定位的浮層。Safari 會把絕對定位的版本擺到欄位外面；flex 列則在各處渲染一致。
- 切換按鈕為 `tabIndex={-1}`，因此在登入表單中按 Tab 是密碼 → 送出，不會繞道一個只改變可見性的按鈕。
- 它帶有 `aria-pressed`，標籤會在顯示／隱藏之間切換——可用 `labels={{ show, hide }}` 覆蓋英文預設值。
- `error` 會設定 `aria-invalid` 並以 `aria-describedby` 關聯訊息。
