import { Checkbox } from "yunui";

受控的复选框。它仅支持受控模式：传入 `checked` 和 `onCheckedChange`。将它与 `<label htmlFor>`（通过 `id` prop）配对，可构成一个无障碍的、点击即可切换的行。

## 导入

```tsx
import { Checkbox } from "@yuhuanowo/yunui";
```

## 用法

`Checkbox` 是受控组件——将它与 state 关联：

```tsx
const [checked, setChecked] = useState(false);
<label className="flex items-center gap-2">
  <Checkbox checked={checked} onCheckedChange={setChecked} id="terms" aria-label="Accept terms" />
  Accept terms
</label>
```

## 如何命名

`Checkbox` 渲染的是 `<button role="checkbox">`。`<label>`——不论是包住它还是用 `htmlFor`——**都无法命名它**：label 只对真正的表单控件有效。请用 `aria-label`，或让 `aria-labelledby` 指向旁边的文字。

```tsx
<span className="flex items-center gap-2 text-sm">
  <Checkbox checked={checked} onCheckedChange={setChecked} aria-labelledby="terms-label" />
  <span id="terms-label">I accept the terms</span>
</span>
```
