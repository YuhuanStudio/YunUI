import { CustomSelect } from "yunui";

一个完全自定义样式的下拉选择框，支持可选的下拉内搜索、逐项图标与描述，以及完整的键盘操作（方向键、Home/End、Enter、Escape）。它是受控的：传入 `value`、`onChange` 以及一个 `options` 数组。若需要自由输入或可创建的值，请参阅 [Combobox](/docs/components/combobox)；若需要基于 Radix 的组合式部件，请参阅 [Select](/docs/components/select)。

## 导入

```tsx
import { CustomSelect } from "@yuhuanowo/yunui";
```

## 用法

`CustomSelect` 是受控组件 —— 将 `value` 和 `onChange` 与状态绑定：

```tsx
const [value, setValue] = useState("medium");

<CustomSelect
  value={value}
  onChange={setValue}
  searchable
  placeholder="Select a model size"
  options={[
    { value: "small", label: "Small", description: "Fast, lower cost" },
    { value: "medium", label: "Medium", description: "Balanced" },
    { value: "large", label: "Large", description: "Highest quality" },
    { value: "xl", label: "Extra Large", description: "Maximum capacity" },
  ]}
/>
```

## 示例

设置 `searchable` 可在下拉中加入筛选框。每个选项都可以携带一个 `icon` 和一行次要的 `description` 描述。

## 后端驱动的搜索

`searchable` 默认会在客户端过滤传入的 `options`。改为传入 `onSearch` 即可让结果由后端驱动：它会（以 `searchDebounceMs` 去抖动，默认 `250`）带着当前的查询字符串触发，你再用抓取到的结果替换 `options`。搭配 `loading` 可呈现进行中的抓取。

```tsx
const [options, setOptions] = useState<CustomSelectOption[]>([]);
const [loading, setLoading] = useState(false);

<CustomSelect
  searchable
  value={value}
  onChange={setValue}
  options={options}
  loading={loading}
  onSearch={async (query) => {
    setLoading(true);
    setOptions(await searchModels(query));
    setLoading(false);
  }}
/>
```

## 无限滚动

对于长或分页的结果集，传入 `onLoadMore` + `hasMore`。`onLoadMore` 会在列表滚动接近底部时触发（且没有进行中的抓取）;你再将下一页附加到 `options`。它与 `onSearch` 互相独立——可择一或并用。

```tsx
<CustomSelect
  value={value}
  onChange={setValue}
  options={options}
  hasMore={hasMore}
  onLoadMore={() => loadNextPage()}
/>
```
