import { Steps } from "yunui";

纵向步骤条：一串带连接轴线的里程碑列表，标示哪些已完成、哪一步进行中、哪些还在后面。

适用于读者*正处于其中*的线性流程——新手引导、多页表单、安装向导。若只需要一个完成比例，请改用 [`Progress`](/docs/components/progress)。

## 导入

```tsx
import { Steps } from "@yuhuanowo/yunui";
```

## 用法

`steps` 是纯数据——每项是一个 `title` 加可选的 `description`。`current` 是当前步骤的**从 0 起算的索引**：它之前的全部渲染为已完成（实心标记加勾），它本身以主色描边，之后的保持淡出。两个已完成步骤之间的轴线也会填色，让进度一眼可读。

只有当前步骤带 `aria-current="step"`；标记与轴线均为 `aria-hidden`，因此屏幕阅读器听到的是标题列表，而不是一串装饰性数字。

<ComponentPreview title="Steps">
  <div className="w-full max-w-sm">
    <Steps
      current={1}
      steps={[
        { title: "Create an account", description: "Verify your email address." },
        { title: "Add a payment method" },
        { title: "Invite your team", description: "Optional — you can do this later." },
      ]}
    />
  </div>
</ComponentPreview>
