import { CommandPalette } from "yunui";

⌘K 命令面板：居中的浮层，一个输入框、可用键盘操作的结果列表，按 Escape 离开。

刻意设计为受控——`query` 与 `items` 都在你手上——因此同一个组件既能做本地模糊过滤，也能做去抖动的服务器搜索，而它本身不需要知道是哪一种。

## 导入

```tsx
import { CommandPalette, useCommandPaletteShortcut } from "@yuhuanowo/yunui";
```

## 基础用法

方向键移动光标、Enter 选取，因此整份列表不需要鼠标。结果变动时光标会归零，才不会指向一个已经被换掉的行。

## 接线方式

```tsx
const [open, setOpen] = useState(false);
const [query, setQuery] = useState("");
const [items, setItems] = useState<CommandPaletteItem[]>([]);

useCommandPaletteShortcut(() => setOpen(true));   // ⌘K / Ctrl-K

<CommandPalette
  open={open}
  onClose={() => setOpen(false)}
  query={query}
  onQueryChange={(q) => { setQuery(q); void search(q).then(setItems); }}
  items={items}
  loading={loading}
  empty={t("noResults")}
  initial={t("startTyping")}
  labels={{ placeholder: t("search"), title: t("search"), close: t("close") }}
/>
```

## 分组

为项目加上 `group`，连续且同组的项目就会被画在同一个标题底下——不需要嵌套结构，也不需要另外的 section 对象。

```tsx
items={[
  { id: "1", title: "Button", group: "Components" },
  { id: "2", title: "Card",   group: "Components" },
  { id: "3", title: "Tokens", group: "Docs" },
]}
```

## 链接与命令

给项目加上 `href`，那一行就会透过适配器的 `Link` 渲染成真正的锚点——⌘ 点击、中键点击、「在新分页开启」全都可用，状态栏也会显示目的地。不加则渲染为执行 `onSelect` 的 `<button>`。

这个区分比看起来重要：搜索结果**就是**链接，读者想看三则不该每看一则就重开一次面板。而命令（「切换深色模式」）不是链接，应该保持按钮。

## 底部提示列

`footer` 会在列表下方渲染一条提示列——左边结果数、右边键盘图例，用 `justify-between` 排版。不传这个属性就不会渲染这条列。

```tsx
footer={
  <>
    <span>{items.length} 则</span>
    <span className="flex items-center gap-3">
      <span><Kbd>↑</Kbd><Kbd>↓</Kbd> 选择</span>
      <span><Kbd>Enter</Kbd> 开启</span>
      <span><Kbd>Esc</Kbd> 关闭</span>
    </span>
  </>
}
```

## 细节

- 列表是真正的 `role="listbox"`，每一行是 `role="option"`，输入框则是带 `aria-activedescendant` 的 `role="combobox"`——因此方向键移动时屏幕阅读器会念出当前行，而焦点始终留在输入框。
- `loading` 会在输入框那一行显示旋转指示，同时保留画面上既有的结果；只有在没有东西可留时列表才会清空。
- 输入框是 `16px`;再小 iOS Safari 就会在聚焦时放大整页。
- 面板打开时页面停止滚动，浮层通过 portal 渲染，因此不会被任何祖先的 `overflow` 裁切。
- `useCommandPaletteShortcut` 是分开的，已有快捷键层的宿主可以略过它。
