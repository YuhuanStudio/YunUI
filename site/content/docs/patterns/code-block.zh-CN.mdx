import { CodeBlock } from "yunui/patterns";

紧凑的 14px 代码块，提供文件名／语言标头、可选行号、轻量高亮和完整源码复制。传入 `tabs` 可切换示例。超过 16 行时先显示 8 行，可展开／收起；复制始终使用当前分页的完整内容。行号默认关闭。


> **该用哪一个 CodeBlock？** 这一个不带依赖 —— 它用内建的小型 tokenizer 上色，因此在营销页或文档卡片里呈现片段几乎零成本。[`yunui/content` 的 `CodeBlock`](/docs/content/code-block) 才是 Shiki 版：VS Code 等级的高亮、行标示与编辑操作，代价是要加载语法。真正的代码用那个，示意用这个。

## 导入

```tsx
import { CodeBlock } from "@yuhuanowo/yunui/patterns";
```

## 带文件名

设置 `filename` 以显示文件标签而非语言徽章，并设置 `showLineNumbers={false}` 来隐藏行号槽。

<ComponentPreview
  title="带文件名"
  code={`<CodeBlock
  filename="app.tsx"
  showLineNumbers={false}
  code={\`const greeting = "Hello, YunUI";\`}
/>`}
>
  <div className="w-full max-w-xl">
    <CodeBlock
      filename="app.tsx"
      showLineNumbers={false}
      code={`const greeting = "Hello, YunUI";`}
    />
  </div>
</ComponentPreview>

## 标签页

提供一个 `tabs` 数组，即可在一个代码块中切换相关片段。

  ]}
