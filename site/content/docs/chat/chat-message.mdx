import { ChatMessage } from "yunui/chat";
import { Badge } from "yunui";
import { Copy, RefreshCw } from "lucide-react";

A single chat message row: avatar, header (name + badges + timestamp), `children` body, optional reasoning/tool `footer`, and optional `actions`. Actions render in normal document flow below the body so they remain discoverable without hover. The component is presentational: `role` (`user` / `assistant` / `system`) selects default avatar/name, and the host supplies all other content. Pass plain text or a `MarkdownRenderer` from `@yuhuanowo/yunui/content`.

## Import

```tsx
import { ChatMessage } from "@yuhuanowo/yunui/chat";
```

## Example

The assistant row carries a model badge and Copy / Regenerate action slots. Actions stay in normal document flow below the message so touch, keyboard and pointer users can all discover them.

## Markdown bodies

Pair it with `@yuhuanowo/yunui/content` to render a full markdown message body:

```tsx
import { ChatMessage } from "@yuhuanowo/yunui/chat";
import { MarkdownRenderer } from "@yuhuanowo/yunui/content";

<ChatMessage role="assistant" name="Assistant" badges={<Badge>gpt-4o</Badge>}>
  <MarkdownRenderer content={message.content} />
</ChatMessage>
```
