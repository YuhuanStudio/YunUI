聊天模式提供訊息列、智慧捲動清單、受控輸入框和響應式標頭。訊息、執行狀態和本地化文案由 host 提供。`ChatComposer` 可選接收 host 提供的 `sourceItems`、`commandItems` 和 `modelItems`；選擇回呼會傳回穩定的 host id，元件本身不會搜尋、上傳、執行命令或呼叫模型。Markdown 訊息主體可使用 `@yuhuanowo/yunui/content` 渲染。聊天 API 仍位於獨立子路徑 `@yuhuanowo/yunui/chat`。

現有訊息、輸入框和標頭屬性／插槽維持可用，消費端可以沿用目前的狀態與回呼接線；新版外觀由 YunUI 公開元件提供，應用不必重畫這些介面或複製其樣式。

## 安裝

聊天子路徑隨 YunUI 一同發佈。若聊天需要渲染 Markdown 或其他富文字內容，請依[內容概覽](/docs/content)說明安裝選用的 content 對等依賴和樣式：

```bash
pnpm add @yuhuanowo/yunui
```

## 匯入

```tsx
import {
  ChatMessage,
  ChatMessageList,
  ChatComposer,
  ChatHeader,
} from "@yuhuanowo/yunui/chat";
```

## 各個部件

每個構件都單獨匯出，你也可以自行拼裝版面：

- [聊天訊息](/docs/chat/chat-message) —— 單列：頭像、標頭、主體、頁尾與常駐操作。
- [聊天訊息清單](/docs/chat/chat-message-list) —— 帶智慧貼底的捲動容器。
- [聊天輸入框](/docs/chat/chat-composer) —— 受控輸入框，支援 Enter 送出和選用的 host 來源、命令、模型選單。
- [Agent 時間軸](/docs/ai/agent-timeline) 與 [授權問題](/docs/ai/approval-question) —— host 提供的活動列與受控問答流程。
- [聊天標頭](/docs/chat/chat-header) —— 帶插槽的響應式標頭外殼。
