The chat pattern provides message rows, a smart-scrolling list, a controlled composer, and a responsive header. The host supplies messages, execution state, and localized copy. Optionally pass host-owned `sourceItems`, `commandItems`, and `modelItems` to `ChatComposer`; selection callbacks return stable host ids, and the component does not search, upload, execute a command, or call a model. Markdown message bodies can use `@yuhuanowo/yunui/content`. The chat API remains on its own subpath, `@yuhuanowo/yunui/chat`.

Existing message, composer and header props/slots remain available. Consumers can keep their current state and callback wiring; the updated appearance comes from YunUI's public components, so apps do not need to redraw these surfaces or copy their styles.

## Install

The chat subpath ships with YunUI. If your chat renders Markdown or other rich content, install the optional content peers and styles described in the [Content overview](/docs/content).

```bash
pnpm add @yuhuanowo/yunui
```

## Import

```tsx
import {
  ChatMessage,
  ChatMessageList,
  ChatComposer,
  ChatHeader,
} from "@yuhuanowo/yunui/chat";
```

## The pieces

Each block is exported standalone so you can assemble your own layout:

- [Chat Message](/docs/chat/chat-message) — a single row: avatar, header, body, footer and persistent actions.
- [Chat Message List](/docs/chat/chat-message-list) — the scroll container with smart stick-to-bottom.
- [Chat Composer](/docs/chat/chat-composer) — the controlled input with Enter-to-send and optional host-fed source, command and model menus.
- [Agent Timeline](/docs/ai/agent-timeline) and [Approval Question](/docs/ai/approval-question) — host-fed activity rows and controlled user-question flow.
- [Chat Header](/docs/chat/chat-header) — the responsive header with slots.
