聊天模式提供消息行、智能滚动列表、受控输入框和响应式头部。消息、执行状态和本地化文案由 host 提供。`ChatComposer` 可选接收 host 提供的 `sourceItems`、`commandItems` 和 `modelItems`；选择回调会返回稳定的 host id，组件自身不会搜索、上传、执行命令或调用模型。Markdown 消息主体可以使用 `@yuhuanowo/yunui/content` 渲染。聊天 API 仍位于独立子路径 `@yuhuanowo/yunui/chat`。

现有消息、输入框和头部属性／插槽保持可用，消费者可以沿用当前的状态与回调接线；新版外观由 YunUI 公共组件提供，应用无需重画这些界面或复制其样式。

## 安装

聊天子路径随 YunUI 一同发布。若聊天需要渲染 Markdown 或其他富文本内容，请按[内容概览](/docs/content)说明安装可选的 content 对等依赖和样式：

```bash
pnpm add @yuhuanowo/yunui
```

## 导入

```tsx
import {
  ChatMessage,
  ChatMessageList,
  ChatComposer,
  ChatHeader,
} from "@yuhuanowo/yunui/chat";
```

## 各个部件

每个构件都单独导出，你也可以自行拼装布局：

- [聊天消息](/docs/chat/chat-message) —— 单行：头像、标头、主体、页脚与常驻操作。
- [聊天消息列表](/docs/chat/chat-message-list) —— 带智能贴底的滚动容器。
- [聊天输入框](/docs/chat/chat-composer) —— 受控输入框，支持 Enter 发送和可选的 host 来源、命令、模型菜单。
- [Agent 时间轴](/docs/ai/agent-timeline) 与 [授权问题](/docs/ai/approval-question) —— host 提供的活动行与受控问答流程。
- [聊天头部](/docs/chat/chat-header) —— 带插槽的响应式头部外壳。
