import { InlineCitation } from "yunui/content";

A claim-adjacent evidence marker for grounded AI content. The compact pill sits inline in the reading flow; hovering or focusing it previews the concrete source — title, location and a bounded excerpt — and clicking delegates navigation to the host via `onOpen`.

## Import

```tsx
import { InlineCitation } from "@yuhuanowo/yunui/content";
```

## Basic

The pill stays in the text; hover it to see the source preview.

<ComponentPreview title="Basic">
  <p className="max-w-md text-sm leading-relaxed text-muted-foreground">
    The Eiffel Tower was completed in 1889
    <InlineCitation
      label="1"
      title="Eiffel Tower — Wikipedia"
      meta="en.wikipedia.org"
      description="Construction of the Eiffel Tower finished on 15 March 1889; it was the tallest man-made structure in the world until 1930."
    />
    and stands 330 metres tall.
  </p>
</ComponentPreview>

## Label & icon

`label` is the compact text in the pill (a number, a short source name); pass an `icon` (e.g. a favicon) to prefix it.

<ComponentPreview title="Label & icon">
  <p className="max-w-md text-sm leading-relaxed text-muted-foreground">
    Transformers replaced recurrence with self-attention
    <InlineCitation
      label="Vaswani et al."
      title="Attention Is All You Need"
      meta="arxiv.org · p.3"
      description="The Transformer relies entirely on an attention mechanism to draw global dependencies between input and output, dispensing with recurrence and convolutions."
    />
    in 2017.
  </p>
</ComponentPreview>

## Opening the source

Pass `onOpen` to make the pill actionable — it fires on click and reveals an external-link affordance in the preview. Navigation (open a URL, scroll to a document location) belongs to the host.

```tsx
<InlineCitation
  label="1"
  title="Eiffel Tower — Wikipedia"
  meta="en.wikipedia.org"
  onOpen={() => window.open("https://en.wikipedia.org/wiki/Eiffel_Tower", "_blank")}
/>
```
