The full content renderer. Give it a markdown string and it renders GitHub-flavored markdown (tables, task lists, strikethrough), KaTeX math (inline `$…$` and block `$$…$$`), Shiki-highlighted fenced code blocks, ` ```mermaid ` diagrams, GitHub-style `> [!NOTE]` callouts, heading anchors, and lazy, zoomable images — all in one component. Rewrite image/link URLs with `urlTransform`, and pass `onCodeEdit` to surface an "Edit" button on code blocks.

## Import

```tsx
import { MarkdownRenderer } from "@yuhuanowo/yunui/content";
```

Requires `@yuhuanowo/yunui/content.css` and `katex/dist/katex.min.css` to be imported by the host app, plus the content peer dependencies (see [Content overview](/docs/content)).

## Usage

```tsx
<MarkdownRenderer
  content={message.content}
  urlTransform={(url) => (url.startsWith("/") ? `${API_HOST}${url}` : url)}
  onCodeEdit={({ code, language, filename }) => openInEditor({ code, language, filename })}
/>
```

Raw HTML in the Markdown input is sanitized after heading IDs are generated and before KaTeX math rendering. Common formatting and supported Markdown features such as GFM tables, task-list checkboxes, callouts, and code highlighting remain available. Unsafe or unsupported raw HTML is cleaned: scripts, iframes, embedded objects, inline event handlers, and unsafe attributes such as inline styles are removed. This is input sanitization for this renderer, not a guarantee that arbitrary content is risk-free.

`urlTransform` can rewrite image and link URLs, but the rewritten result still passes through React Markdown's safe-protocol filter. Relative URLs and supported protocols such as `http:`, `https:`, `mailto:`, `irc:`, `ircs:`, and `xmpp:` are accepted; unsafe protocols such as `javascript:` and `data:` are rejected.

`linkOrigin` optionally supplies a stable site origin for link classification in both SSR and the browser. Same-origin absolute links are treated as internal; other absolute links are external. Without `linkOrigin`, absolute HTTP(S) and protocol-relative URLs are external, while relative and fragment links are internal.

```tsx
<MarkdownRenderer content={markdown} linkOrigin="https://example.com" />
```
